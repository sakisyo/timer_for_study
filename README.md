# timer_for_study — 勉強タイマー

集中して勉強するための、ブラウザで動くシンプルなカウントダウンタイマーです。
プリセットから時間を選んで「開始」を押すだけ。残り時間は円形のプログレスリングで一目でわかります。

## 機能

- **プリセット時間の選択** — 5 / 10 / 15 / 20 / 25 / 30 / 45 / 60 / 90 分（ポモドーロ用の 25 分がデフォルト）
- **円形プログレスリング** — 残り時間を SVG の円グラフで可視化。実行中はリングが脈動します
- **開始 / 一時停止 / リセット** — 一時停止しても残り時間は保持され、続きから再開できます
- **完了通知** — 0:00 になると3音の上昇チャイムが鳴り、数字の色が変わって「🎉 お疲れ様でした！」が表示されます
- **レスポンシブ対応** — スマートフォンでもそのまま使えます

実行中はプリセットボタンが無効になり、誤操作で時間が変わらないようになっています。

## 使い方

ビルド作業は不要です。

```bash
git clone https://github.com/sakisyo/timer_for_study.git
cd timer_for_study
open study-timer.html      # macOS の場合。Windows は start、Linux は xdg-open
```

`study-timer.html` をブラウザで直接開くだけで動きます。

> **注意**: React / Tailwind CSS を CDN から読み込んでいるため、**初回起動時はインターネット接続が必要**です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `study-timer.html` | **本体**。これ 1 つで完結します（HTML + CSS + React コンポーネント） |
| `study-timer.jsx` | React コンポーネント単体版。他の React プロジェクトへ組み込む用 |

`study-timer.jsx` は既存の React プロジェクトに import して使うことを想定した別バージョンです。
`lucide-react` と Tailwind CSS が導入済みの環境が前提で、UI は HTML 版より簡素なつくりになっています。

## 技術スタック

- React 18（UMD ビルドを CDN から読み込み）
- Babel Standalone（ブラウザ内で JSX をトランスパイル）
- Tailwind CSS（CDN 版）
- Web Audio API（完了チャイムをその場で合成。音声ファイルは同梱していません）
- SVG（プログレスリング）+ CSS backdrop-filter（グラスモーフィズム UI）

Node.js もパッケージマネージャも使いません。学習用の小さなアプリとして、環境構築なしで動かせることを優先しています。

## 既知の制限

- **本番運用向けではありません** — Babel Standalone によるブラウザ内トランスパイルを使っているため、初回表示に数百 ms かかります。実運用するなら Vite などで事前ビルドしてください
- **状態は保存されません** — ページを再読み込みするとタイマーはリセットされます
- **バックグラウンドタブでは時間がずれます** — ブラウザのタイマー抑制により、非アクティブなタブではカウントが実時間より遅れることがあります
